# 4.14 Cross-currency transfer

- **Status:** `todo`
- **Goal:** `/transfer` between two banks of different currencies converts the source amount, shows the destination amount and the rate, and writes only after Yes.
- **Depends on:** `3.11` same-currency `/transfer`, and [`4.13.3`](4.13.3-currency-picker.md).

Do **not** implement this umbrella as one session. Next pickup is [`4.14.1`](4.14.1-fx-rates.md).

The feed needs **no API key**. Do not ask the operator for a token. Freshness, cache lifetime, and HTTP timeout are separate env vars with defaults in code (`FX_FRESH_TTL`, `FX_CACHE_TTL`, `FX_HTTP_TIMEOUT`). Do not reuse `BOT_TTL`.

| Step | File | Goal |
| --- | --- | --- |
| 4.14.1 | [FX rates](4.14.1-fx-rates.md) | Fetch USD-based rates, cache them in Redis, expose `Quote` |
| 4.14.2 | [FX transfer](4.14.2-fx-transfer.md) | Confirm and write a converted `/transfer` |

**Not here:** changing a bank’s currency (that keeps the number; [`4.13.3`](4.13.3-currency-picker.md)). `/all` and `/total` stay grouped and unconverted ([`4.13.2`](4.13.2-currency-display.md)). No hardcoded rate table.
