# 4.14 Balances and FX transfer

- **Status:** `todo`
- **Goal:** a bank holds one balance per currency. `/transfer` moves a chosen source currency onto a chosen destination currency. The same currency writes immediately. Different currencies, including two currencies in one bank, show the converted amount and the rate, and write only after Yes.
- **Depends on:** `3.11` same-currency `/transfer`, and [`4.13.3`](4.13.3-currency-picker.md).

Do **not** implement this umbrella as one session. Next pickup is [`4.14.1`](4.14.1-fx-rates.md). [`4.14.2`](4.14.2-currency-balances.md) lands before [`4.14.3`](4.14.3-fx-transfer.md).

The feed needs **no API key**. Do not ask the operator for a token. Freshness, cache lifetime, and HTTP timeout are separate env vars with defaults in code (`FX_FRESH_TTL`, `FX_CACHE_TTL`, `FX_HTTP_TIMEOUT`). Do not reuse `BOT_TTL`.

| Step | File | Goal |
| --- | --- | --- |
| 4.14.1 | [FX rates](4.14.1-fx-rates.md) | Fetch USD-based rates, cache them in Redis, expose `Quote` |
| 4.14.2 | [Currency balances](4.14.2-currency-balances.md) | Several balances per bank. Retire `/currency`. Same-currency `/transfer` |
| 4.14.3 | [FX transfer](4.14.3-fx-transfer.md) | Confirm and write a converted `/transfer`, including inside one bank |

**Not here:** a converted `/all` or `/total`. A command that deletes one currency. Per-currency include-in-total. A hardcoded rate table.

`4.13` shipped one balance per bank and a `/currency` relabel. `4.14.2` replaces that model. Do not reopen `4.13` to do it.
