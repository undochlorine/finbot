# 4.13.2 Currency display

- **Status:** `todo`
- **Goal:** every balance the bot already shows names its currency. `/all` and `/total` list one line per currency and do not convert.
- **Depends on:** [`4.13.1`](4.13.1-currency-model.md).
- **Read with this file:** [`requirements.md`](../requirements.md) (Currencies and FX), [`areas/telegram.md`](../areas/telegram.md), [`areas/service.md`](../areas/service.md), [`areas/persistence.md`](../areas/persistence.md).

Until [`4.13.3`](4.13.3-currency-picker.md) every bank is `USD`, so this step’s visible result is `$` on existing amounts.

## In scope

- Replace every user-facing `Money.Format()` with `domain.FormatMoney(amount, bankCurrency)`. Grep handlers and `internal/text` call sites. Known money slots: `AddedFmt`, `SpentFmt`, `SetToFmt`, `BankCardIncludedFmt`, `BankCardExcludedFmt`, `ToggledIncludedFmt`, `ToggledExcludedFmt`, `TransferredFmt`, and the total block.
- Amount questions name the unit and still ask for a number only. Examples: `How much should I add to "Travelling" ($)?`, `How much should I transfer from "A" to "B" ($)?` (source bank). `/add`, `/spend`, `/set`, and `/transfer` reject a currency token the same way they reject any other non-amount (`$100`, `100 USD`).
- Same-currency `/transfer` is unchanged, including `ErrCurrencyMismatch` when the two banks differ. Format the moved amount and both balances with that shared currency.
- Replace the single `SUM` used by `/total` and by the total block of `/all`.
  - Repository: `SELECT currency, COALESCE(SUM(balance_cents), 0) FROM banks WHERE user_id = $1 AND include_in_total GROUP BY currency`.
  - Service returns that set sorted. Drop the old one-number `Total` helper so nothing can sum across currencies.
  - Sort: `USD`, then `EUR`, then `USDT`, then any other code A→Z. Skip a code that has no included bank. A code whose included banks sum to `0` still appears.
  - No included banks: one line, `$0.00` (default currency).
- Copy for `/total` and the `/all` total block, in `en`, `ru`, `uk`, and `md` (Moldavian stays hand-written):

```text
Total:
$10.00
20.00 USDT
```

  One heading, then one `FormatMoney` line per currency. No converted extra line. Numbers keep `.` in every catalog.

- `/banks` and `/all` bank lines keep today’s shape (`Name: $10.00 (in total)`). Excluded banks stay in the list and stay out of the total block.
- `/bank` uses the same card line.
- Delete copy that does not show a balance stays without one.

## Out of scope

- Picker, `/currency`, `users.last_currency` writes ([`4.13.3`](4.13.3-currency-picker.md))
- Letting `/newbank` store anything but the current create path
- Removing `ErrCurrencyMismatch`
- FX ([`4.14`](4.14-fx-transfer.md))

## DoD

- No user-visible balance is a bare `123.45`
- `/total` and `/all` with two included currencies emit two amount lines and no cross-currency sum
- Excluded banks do not affect those lines
- Add/spend/set/transfer shortcuts still take a number only
- `make test-unit`, `make lint`, and `make test-integration` pass

## Tests

- Service: included banks in `USD` and `UAH` return two groups, sums are per code, excluded banks are absent, empty included set is `USD` + `0`, sort is `USD`, `EUR`, `USDT`, then A→Z.
- Handler or text test: a `USD` card renders `$10.00`; a `UAH` card renders `10.00 UAH`; a negative `USD` balance renders `-$1.00`.
- Integration: the grouped SQL matches two currencies for one user and ignores another user’s rows.
