# 4.12 Language picker

- **Status:** `done`
- **Goal:** `/language` with a **short** list of catalogs. Languages chosen with the user at the start of this step (not every language).
- **Depends on:** locale column + keyed `internal/text` from `3.6`.
- **Languages:** English (default, `en`), Russian (`ru`), Ukrainian (`uk`), Moldavian (`md`). First `/start` asks via buttons; `/language` can change it later. Slash commands stay untranslated. Command-menu descriptions stay English (`setMyCommands` is bot-wide). Moldavian copy lives in `catalog_md.go` and is maintained by hand.
