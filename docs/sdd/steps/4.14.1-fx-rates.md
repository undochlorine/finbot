# 4.14.1 FX rates

- **Status:** `todo`
- **Goal:** a `Quote` from one currency to another, backed by a public feed and a Redis cache.
- **Depends on:** [`4.13.3`](4.13.3-currency-picker.md) so the currency codes exist. The adapter itself only needs currency codes from [`4.13.1`](4.13.1-currency-model.md). [`4.14.3`](4.14.3-fx-transfer.md) is what `/transfer` calls. [`4.14.2`](4.14.2-currency-balances.md) does not call `Quote`.
- **Read with this file:** [`requirements.md`](../requirements.md) (Currencies and FX), [`areas/service.md`](../areas/service.md), [`areas/telegram.md`](../areas/telegram.md) (Redis `Cache` only).

`cmd/bot` does not call this yet.

## Feed

[Fawaz Ahmed’s currency API](https://github.com/fawazahmed0/exchange-api), no account and no key. Checked 2026-11-08: `date` `2026-11-07`, `eur`, `uah` (`45.28…`), `usdt` (`1.002…`), `usd` `1`. About 340 codes. Updated daily.

Primary, then fallback only when the primary does not return a parseable JSON body (network error, non-200, invalid JSON):

- `https://cdn.jsdelivr.net/npm/@fawazahmed0/currency-api@latest/v1/currencies/usd.min.json`
- `https://latest.currency-api.pages.dev/v1/currencies/usd.min.json`

Send `User-Agent: finbot`. One attempt times out after `FX_HTTP_TIMEOUT` (default `3s`). Decode with `UseNumber` so rates stay decimal strings. Shape: top-level `date`, and `usd` as an object of lowercase code → units of that currency for **1 USD**.

A parsed body that simply lacks one code is a missing rate, not a failed fetch. Do not try the fallback in that case.

## Cache

Redis through the existing cache port (`Get` / `Set` / TTL). The fx adapter owns a small cache interface (Get and Set only) and a small `Doer`; mockery mocks those. Do not import the telegram adapter. `cmd/bot` will pass the Redis cache in `4.14.3`.

- Key suffix `fx:usd` (the Redis adapter prefix makes it `finbot:v1:fx:usd`).
- Value JSON: `{"fetched_at":"<RFC3339>","rates":{"USD":"1","EUR":"0.89","UAH":"45.28","USDT":"1.002"}}` with uppercase codes and decimal strings.
- Redis TTL is `FX_CACHE_TTL` (default `24h`) from the last successful `Set`.
- If `fetched_at` is younger than `FX_FRESH_TTL` (default `1h`), return it and do not call HTTP.
- If it is older, try HTTP. Success replaces the key. Failure returns the cached rates while the key is still there.
- No key and both URLs failed → quote error. Do not cache failures.
- One in-process singleflight around a miss/refresh so one bot process does not stampede. A second process is out of scope (`4.9`).

## API

Owned by **service** (the consumer). Mockery next to service tests when `4.14.3` calls it. This step’s adapter tests mock the adapter’s own HTTP and cache interfaces.

```go
type RateQuote struct {
    From          string   // canonical code
    To            string
    DestPerSource *big.Rat // units of To for 1 From
}

type RateProvider interface {
    Quote(ctx context.Context, from, to string) (RateQuote, error)
}
```

- Equal codes return `1/1` and do not touch HTTP or Redis.
- Otherwise `DestPerSource = rate(to) / rate(from)` using the USD table (`rate` = units per 1 USD).
- Missing code, non-positive rate, or unparsable rate → a sentinel the handler can recognize (`ErrRateUnavailable`). Do not invent a peg for USDT.
- `math/big.Rat` only. Do not put `float64` in the quote or in the cache.

Package: `internal/adapter/fx`. Config struct there, `envPrefix:"FX_"`, wired through `config.ParseConfig` in this step (the bot still does not call `Quote`).

| Variable | Default | Rule |
| --- | --- | --- |
| `FX_FRESH_TTL` | `1h` | Go duration, `> 0`. Younger cache skips HTTP |
| `FX_CACHE_TTL` | `24h` | Go duration, `> 0`, and `>= FX_FRESH_TTL`. Redis key lifetime |
| `FX_HTTP_TIMEOUT` | `3s` | Go duration, `> 0`. One attempt |

`envDefault` holds those defaults. Add the three names to `clearEmptyOptionalEnv` so a blank value keeps the default. Do not read `BOT_TTL` for any of them. Document them in README, `docs/sdd/areas/platform.md`, and `.env.example`. Compose passes them the same way it passes `BOT_TTL`.

## DoD

- `Quote("USD","UAH")` matches `uah/usd` from a fixture body
- `Quote("EUR","UAH")` matches `uah/eur`
- `Quote("UAH","USD")` is the inverse
- Fresh cache performs no HTTP; stale cache survives an HTTP failure; empty cache plus two failures returns `ErrRateUnavailable`
- Primary transport failure then a good fallback is a success and a `Set`
- Unset or blank `FX_*` keeps `1h` / `24h` / `3s`. `0`, a negative duration, or `FX_CACHE_TTL` shorter than `FX_FRESH_TTL` fails startup
- `make test-unit` and `make lint` pass. Integration against live Redis is not required if the cache is mocked at the adapter boundary.

## Tests

Table-driven quote math from a fixed JSON fixture, plus the cache/fallback cases above. Drive those cases with the configured durations, not a second hardcoded clock window. Use mockery for the adapter’s cache and HTTP interfaces. A custom double needs a written reason and user approval; do not add one here.

Config tests: omitted and blank vars use the defaults; `0`, `-1s`, and `FX_CACHE_TTL=30m` with `FX_FRESH_TTL=1h` fail.
